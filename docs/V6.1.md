# V6.1 Frozen Model Specification

This document records the frozen theory contract for implementation. The operational system is a continuous state-space estimator, not a deterministic crisis predictor.

## Objective

The system answers five questions:

1. What exogenous shock occurred?
2. Through which geography and lag structure can it propagate?
3. How do the financial, physical-delivery and AI-productivity systems interact?
4. Is market functioning deteriorating?
5. Has that deterioration created a verifiable asset mispricing?

Pipeline:

```text
Exogenous shocks
  -> spatial / lag routing
  -> state estimation
  -> market stress
  -> opportunity detection
  -> permanent impairment filter
```

## State vector

```text
R_t = [A, B, C1, C2, C3, D]
```

Each element is bounded in [0,1] and is an **activation intensity, not a probability**.

- A: AI productivity realization
- B: financial microstructure deleveraging
- C1: core-economy stagflation
- C2: peripheral sovereign stress
- C3: industrial-capital-goods inflation
- D: financial repression

The latent structure is:

```text
z_t = F z_(t-1) + B X_t + G J_t + epsilon_t
R_t = sigmoid(z_t)
```

where J_t contains discontinuous policy/geopolitical jumps that should not be smoothed away.

## Different persistence by state

The states have materially different memory:

- B: days
- C1/C2: months
- C3: months to quarters
- A: quarters
- D: quarters to years

A one-day repo disruption may move B quickly. One weak earnings report must not collapse A.

## Point-in-time data contract

Every observation must carry enough time metadata to reconstruct what was knowable at a historical decision point:

```text
observation period
published_at
available_at
ingested_at
revision / vintage
source
confidence
```

Hard rule:

```text
available_at <= decision_time
```

Missing data remains missing. It is never silently mapped to zero.

## Freshness semantics

Freshness uses a true half-life:

```text
freshness = exp(-ln(2) * age / half_life)
```

Stale data does not mechanically drag the state toward zero. Instead it increases measurement uncertainty.

## Stress Engine

Regime and Stress are separate.

Regime answers: **where is pressure coming from?**

Stress answers: **how badly is market function impaired?**

Stress tracks three functions:

- Funding
- Price discovery
- Intermediation

Operational levels:

- L1: functions normal
- L2: at least one function under material pressure
- L3: at least two functions impaired
- L4: sovereign/liquidity controller intervenes while private markets are still forcibly deleveraging

Escalation should be fast and normalization slow; hysteresis is mandatory.

## Indicator families

The frozen indicator dictionary contains 17 first-level indicators spanning:

- Treasury basis / margin strain
- Repo and dealer balance-sheet stress
- Treasury auction quality
- AI productivity contribution
- GPU economic obsolescence
- Private credit
- Interconnection execution
- Transformer / switchgear lead times
- Hormuz disruption
- Treasury issuance duration
- regulatory / reserve intervention
- financial repression asset-gap behavior
- ENSO
- crop balance
- hydro-gas stress
- Panama / Hormuz chokepoints
- external sovereign stress adjusted for backstop capacity

The canonical machine-readable list is `config/indicators.yaml`.

## C1 / C2 / C3 separation

These are deliberately separate states:

- C1: inflation/stagflation transmission into core economies
- C2: FX/reserve/external-debt feedback in vulnerable sovereigns
- C3: industrial-capital-goods inflation that compresses project IRR

They must not be collapsed into a single inflation state.

## Opportunity Engine

Three opportunity classes are evaluated only after the state and stress layers:

- B-Fat: forced liquidation where price deteriorates faster than earnings
- C-Fat: physical bottleneck where earnings improve faster than valuation
- D-Fat: persistent repression where real assets reprice relative to cash/fixed nominal claims

Every signal must pass a Permanent Impairment Filter. Structural business deterioration, technological obsolescence, unfinanceable debt, permanent loss of pricing power, permanent customer loss, or sharply falling replacement cost can switch FatPitch to OFF even after large price declines.

Conceptually:

```text
Opportunity =
  Hard Bottleneck
  * Hard Cash Flow
  * Soft Price
  * (1 - Permanent Impairment)
```

## Backtesting

The project uses walk-forward tests only. Parameters must not be tuned with knowledge of future test periods.

Historical model layers:

- Core-1: 2006-2009
- Core-2: 2010-2019
- Core-3: 2020-2023
- New Module: 2024-2026

Modern AI/GPU/private-credit features must not be synthesized into periods where they did not exist.

Primary diagnostics include crisis lead time, episode recall, false alarms, false negatives, persistence, transition counts, monotonicity of future stress versus state intensity, opportunity quality, sensitivity testing, and missing-data robustness.

## Implementation order

1. Freeze indicator definitions and data dictionary.
2. Build point-in-time raw data and vintage layer.
3. Build signal normalization/freshness/confidence handling.
4. Implement Stress Engine first.
5. Implement transparent regime baseline before complex filtering.
6. Run walk-forward historical validation.
7. Validate AI/GPU/private-credit as a separate modern module.
8. Run shadow mode before any opportunity scanner is considered mature.

## Non-goals

The first phase must not:

- optimize parameters to make 2008 look good;
- overweight current fears;
- use LLM judgments as raw observations;
- treat news sentiment as a direct state input;
- fill missing data with zero;
- use revised future-known data in historical tests;
- auto-trade.

V6.1 is therefore best understood as an auditable state-estimation and falsification framework for productivity, physical constraints, financial fragility, sovereign intervention and exogenous shocks.
