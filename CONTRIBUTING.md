# Contributing

The project prioritizes reproducibility over adding more indicators.

For every new source or feature, document:

- economic meaning
- canonical publisher/source
- observation period
- publication time and known release lag
- revision policy
- historical availability
- missing-data behavior
- expected frequency and half-life
- whether point-in-time vintages are obtainable

Pull requests that silently backfill revised future-known values into historical tests should not be merged.
